# The Lighthouse drive

Lighthouse is a demo company on RosterDock. This folder is its shared drive: every teammate can read it, and
a write here is a proposal a person approves. Everything in it is fictional except the fact sheet, which
describes RosterDock itself.

| Folder       | What                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| `company/`   | `rosterdock-fact-sheet.md` (the only source of product claims), `brand-voice.md` |
| `crm/`       | The CRM export: one CSV per export date. Fictional companies.                    |
| `finance/`   | The month's bank transactions and the chart of accounts. Fictional.              |
| `site/`      | The published website. Written only through an approved write.                   |
| `published/` | Published writing (posts, emails, reports). Written only through approval.       |

Scratch work goes to the staging folder instead (`~/Lighthouse/staging`), which teammates write freely.
