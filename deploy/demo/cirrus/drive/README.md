# The Cirrus drive

Cirrus is a demo company on RosterDock: a fictional UK provider of broadband, TV and mobile. This folder is
its shared drive: every teammate can read it, and a write here is a proposal a person approves. Every
customer, contact, incident, price, policy and programme in it is invented.

| Folder       | What                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| `company/`   | `cirrus-fact-sheet.md` (the only source of product and price claims), `brand-voice.md` |
| `policies/`  | Compensation, priority customers, and what the care assistant may and may not say      |
| `care/`      | The week's customer contacts (one CSV per week) and the help centre's articles         |
| `network/`   | The month's incident log                                                               |
| `content/`   | The Stream catalogue and the week's viewing figures                                    |
| `published/` | What goes to customers and colleagues. Written only through an approved write.         |

Scratch work goes to the staging folder instead (`~/Cirrus/staging`), which teammates write freely.
