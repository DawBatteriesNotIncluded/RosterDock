# Milestone 0: foundation

Status as of 2026-09-12. The plan (`docs/plan.html`) defines M0 as: repo, CI, Compose, schema and
migrations, auth with roles, event stream, React shell with the prototype tokens, teammates as
first-class accounts, Helm skeleton. Demo: create a company, a department, a project and a task in
the UI; a second browser sees them appear live. Done when every mutating route has a role check
and an event.

## Demo script

```bash
pnpm install && pnpm db:up && pnpm db:migrate && pnpm dev
```

1. Open http://localhost:5173 in two browsers. Sign in with any email (dev login).
2. Company switcher, Create a company.
3. Teammates, Hire from template: Peter, then Cody.
4. Departments, Create department: Engineering, lead Peter. Click Cody's cell in the matrix: Member.
5. Company, New project. New task, assigned to Cody in Engineering.
6. The second browser shows the task in the rail and Cody as queued, without a reload.
7. Drag the card to Done: refused with a toast. Drag to In progress: the card shows Running.
8. Write `@cody start with the outbound-mail sub-workflow` on the task: routed to Cody.

## Decisions taken while building

- Teammates authenticate with per-company bearer tokens minted by an owner or admin
  (`POST /teammates/:id/tokens`, hash stored, shown once). Run-scoped tokens (M1) reuse the same table.
- Task numbers are dense per company (`#144`) and event seq is dense per company, both allocated under
  the `company_counters` row lock inside the mutation transaction.
- `Done` is unreachable from any route in M0. The move endpoint returns 409 with the reason; the
  review approval path lands in M3.
- Moving to `doing` is refused while a dependency is not done, with a `dependencies_unresolved` blocker
  in the response so the UI can show it.
- Blocker codes: the governance-ladder codes from v1 are gone; `waiting_on_teammate` was added so the
  Blocked column has its three reasons: dependency, teammate, approval.
- Matrix cell cycle is none, member, lead, out. Promoting a member to lead demotes the previous lead.
- `BOARD_PORT` takes precedence over `PORT` so a dev-server wrapper that injects `PORT` for the web
  cannot capture the board.
- MinIO's Docker Hub image is retired and `quay.io/minio/minio` now needs a login; Compose and the smoke
  script pull Chainguard's build, `cgr.dev/chainguard/minio`. It has no `curl`, so the healthcheck is
  `mc ready local`, and it runs as a non-root user, so the smoke pod mounts an `emptyDir` at `/data`.

## Not in M0 (by design)

- OIDC login: dev login and bearer tokens only. The `auth/` seam is where OIDC lands (M6 per the plan).
- Reviews, Approvals, Office, Costs, Settings show their milestone and a description.
- shadcn: only the `cn` helper and a Button in shadcn style; components arrive with the screens that
  need them.
- "New goal" and "Ask Peter to design a team" are disabled with a tooltip until M4.
